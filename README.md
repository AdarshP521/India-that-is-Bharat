# INDIA
## A landing page of India Built using GSAP


## 🛠️ Quick Start & Setup

### 1. Initialize Vite Project
To set up a fresh project in the current directory:

```bash
npm create vite@latest .
```

### 2. Clean Up Starter Files
1. Delete `counter.js`.
2. Clear `src/main.js` and keep only:
   ```js
   import './style.css';
   ```
3. Clear `src/style.css` and add a basic reset:
   ```css
   * {
     margin: 0;
     padding: 0;
     box-sizing: border-box;
   }

   body {
     background-color: black;
   }
   ```
